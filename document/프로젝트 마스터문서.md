## 1) 프로젝트 개요

### 1.1 비전
- **Web(PWA)** 기반 한글/영어 타자 연습 서비스
- 동일 빌드 결과로 **Capacitor(Android/iOS)** 앱 패키징까지 연결

### 1.2 기술 스택
| 구분 | 기술 |
|------|------|
| Frontend | React (Vite), TypeScript, PWA(service worker) |
| Backend | Django, Django REST Framework, PostgreSQL |
| Infra | Docker Compose, Nginx Reverse Proxy |
| Mobile | Capacitor (Android/iOS) — 선택 |

### 1.3 핵심 원칙
- **프론트 계산, 백엔드 저장**: 타자 입력/오타 계산은 프론트, 결과만 API로 저장
- **세션 기반 기록**: 모든 연습 결과는 `TypingSession` 1개로 저장
- **확장 스키마 점진 도입**: 집계(`stats`)·랭킹(`leaderboard`)·챌린지(`challenges`)는 필요 시 활성화

### 데이터 흐름

1. **연습 시작**: PracticePage에서 모드/설정 선택 → texts API 또는 프리로드로 콘텐츠 로딩
2. **입력 처리**: `useTypingEngine` / `useChallengeEngine`에서 실시간 WPM/정확도/콤보 계산
3. **결과 저장**: 
   - 연습: `POST /api/sessions` → TypingSession 저장 + `typingHistory` localStorage 저장
   - 챌린지: `challengeStorage` (best/history) + `typingHistory` localStorage 저장
4. **기록 조회**: HistoryPage에서 연습/챌린지 탭으로 분리 조회
5. **홈페이지 대시보드**: `typingHistory`에서 연속 출석/오늘 목표/세션 통계 실시간 계산
