## 2) 기능 상세 (테이블/화면/API 관점)

### 2.1 목표/루틴 + 스트릭 ⭐ Phase 1 — ✅ 프론트 구현 완료

**핵심 가치**: 매일 "조금씩" 하게 만들고, History가 습관/달성으로 변함

| 항목 | 상세 |
|------|---------|
| **프론트 UI** | ✅ HomePage: 연속 출석, 오늘 목표/진행률, 세션/WPM 통계 |
| **데이터 연동** | ✅ `typingHistory` localStorage 기반 (연습/챌린지 모두 저장) |
| **DB (미구현)** | `stats_user_daily` 활용 또는 `goals_user_goal` 추가 |
| **API (미구현)** | `GET/POST /api/goals/me`, `GET /api/stats/daily` |
| **우선순위** | ✅ 프론트 완료 / ⏳ 백엔드 대기 |

---

### 2.2 오타 Top/패턴 분석 + 맞춤 훈련 ⭐ Phase 1 — ✅ 기본형 구현 완료

**핵심 가치**: "그냥 치는 것" → "교정/성장" 경험 제공

|------|---------|
| **프론트 (1단계)** | ✅ ResultPage에서 오타 Top5 (프론트 계산) |
| | ✅ 오답 노트 UI (단어별 diff 카드 스택) |
| | ✅ "추천 훈련 시작" 버튼 + 약점 훈련 모드 연결 |
| **백엔드 (2단계, 미구현)** | 서버 분석 (이벤트 저장 유저만) |
| **API (미구현)** | `GET /api/insights/summary`, `GET /api/training/recommendations` |
| **우선순위** | ✅ 프론트 완료 / ⏳ 백엔드 대기 |

## 5) 체크리스트 (스키마 기준 확정 포인트)

- [ ] `TypingSession`을 **원천 데이터**로 유지
- [ ] `user_id` NULL 허용 여부 (게스트 지원/기록 이관)
- [ ] 랭킹은 스냅샷 (권장) vs 실시간 (비권장)
- [ ] TypingEvent 저장 정책 (기본 OFF + opt-in + 보관기간)
- [ ] texts soft delete (`is_active`) 정책 확정
- [ ] 핵심 인덱스 `(user_id, started_at DESC)` 적용
