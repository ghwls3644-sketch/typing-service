## 0) 개요

타자 연습(PracticePage) 및 60초 챌린지(ChallengePage)에 **가상 키보드 + 손가락 가이드** UI를 추가.
사용자가 다음에 눌러야 할 키를 시각적으로 확인하고, 올바른 손가락을 사용하도록 안내하는 기능.

### 주요 기능
- QWERTY 키보드 시각화 (5행: 숫자행, 상단행, 홈행, 하단행, 스페이스바)
- 다음 키 하이라이트 (파란색 강조)
- 누른 키 실시간 표시 (keydown/keyup 기반)
- 손가락별 색상 코딩 (8손가락 + 엄지, 키 하단 border에 힌트)
- 손가락 가이드 SVG (좌/우 손 실루엣, 활성 손가락 하이라이트)
- 한글 두벌식 키보드 지원 (한/영 라벨 전환)
- 한글 IME 키스트로크 큐 (음절 분해 → 자모 → 물리키 변환)
- 토글 설정 (키보드 ON/OFF, 손가락 가이드 ON/OFF, 키입력 표시 ON/OFF)

## 1) 구현 방식

**Pure HTML/CSS Grid** 방식을 채택.

| 비교 항목 | HTML/CSS Grid | SVG | 이미지+오버레이 |
|-----------|:---:|:---:|:---:|
| DOM 접근성 | ✅ 우수 | ⚠️ 보통 | ❌ 어려움 |
| 유지보수성 | ✅ CSS 변수 활용 | ⚠️ 좌표 관리 | ❌ 이미지 재작성 |
| 테마 통합 | ✅ 기존 CSS 변수 | ⚠️ fill 속성 | ❌ 별도 이미지 |
| 반응형 | ✅ Grid + media query | ⚠️ viewBox 활용 | ❌ 고정 크기 |
| 성능 | ✅ DOM 리렌더 최소화 | ✅ 좋음 | ⚠️ 오버레이 비용 |

## 3) 핵심 알고리즘

### 3-1. 한글 음절 분해 (hangulDecompose.ts)

유니코드 한글 음절 공식을 사용하여 초성/중성/종성 분리:

```
음절 코드 = 0xAC00 + (초성 × 21 + 중성) × 28 + 종성

예) "한" (U+D55C)
  초성 인덱스 = (0xD55C - 0xAC00) / (21 × 28) = 18 → ㅎ
  중성 인덱스 = ((0xD55C - 0xAC00) % (21 × 28)) / 28 = 0 → ㅏ
  종성 인덱스 = (0xD55C - 0xAC00) % 28 = 4 → ㄴ
```

복합 자모도 분해:
- 복합 중성: ㅘ→[ㅗ,ㅏ], ㅙ→[ㅗ,ㅐ], ㅚ→[ㅗ,ㅣ], ...
- 복합 종성: ㄳ→[ㄱ,ㅅ], ㄵ→[ㄴ,ㅈ], ㄺ→[ㄹ,ㄱ], ...

### 3-2. 두벌식 자모→물리키 매핑 (keyMapping.ts)

```
자모→키: ㄱ→KeyR, ㅏ→KeyK, ㄴ→KeyS, ㅂ→KeyQ, ...
Shift 필요: ㄲ→Shift+KeyR, ㅃ→Shift+KeyQ, ㅆ→Shift+KeyT, ...
```

### 3-3. 키스트로크 큐 모델 (useHangulKeystrokeQueue.ts)

1. `targetText` 전체를 키스트로크 배열로 미리 변환 (메모이제이션)
2. 각 글자별 키스트로크 개수 누적합 계산
3. `userInput.length` 기반으로 소비된 키스트로크 수 추적
4. `useKeyboardHighlight`에 다음 미소비 키스트로크 전달

```
"한글" → 키스트로크 큐:
  한: [KeyG(ㅎ), KeyK(ㅏ), KeyS(ㄴ)]
  글: [KeyR(ㄱ), KeyF(ㅡ), KeyF(ㄹ)]
  큐: [KeyG, KeyK, KeyS, KeyR, KeyF, KeyF]

사용자 입력 "한" 완료 → 소비 3개 → 다음 하이라이트: KeyR(ㄱ)
```

### 3-4. 영문 다음 키 계산 (useKeyboardHighlight.ts)

```
다음 문자 = targetText[userInput.length]
매핑 = CHAR_TO_KEY[다음 문자]  // 예: 'A' → {code: 'KeyA', shift: true}
하이라이트 키: [매핑.code] + (shift 필요 시 ['ShiftLeft'])
```

## 4) 컴포넌트 구조

### 4-1. VirtualKeyboard

- **Props**: `nextKeys`, `pressedKeys`, `language`, `showPressedKeys`, `showFingerColors`
- CSS Grid 5행 레이아웃 (각 행의 offset으로 계단식 배치)
- 키 상태별 CSS 클래스:
  - `.key--highlight`: 다음 키 (파란색 배경 + 글로우)
  - `.key--pressed`: 현재 누른 키 (밝은 배경 + scale 축소)
  - `.key--space`: 스페이스바 (넓은 width)
- 한/영 모드에 따라 `labelKo`/`label` 전환, 서브라벨로 반대 언어 표시

### 4-2. HandGuide

- **Props**: `activeFingers` (활성 손가락 배열)
- 좌/우 손 SVG 실루엣 (손바닥 + 5개 손가락)
- 활성 손가락: 손가락별 지정 색상으로 fill + drop-shadow 효과
- 비활성 손가락: 회색 반투명

### 4-3. KeyboardWithGuide (래퍼)

- VirtualKeyboard + HandGuide를 함께 렌더링
- `showKeyboard`/`showHandGuide` 설정에 따라 조건부 렌더링
- 다음 키의 `finger` 정보를 추출하여 HandGuide에 전달
