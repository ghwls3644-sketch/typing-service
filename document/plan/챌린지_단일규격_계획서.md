# 타자 연습 서비스 계획서 (연습 → 챌린지)

## 0. 방향성
- **연습(Practice)**: 난이도 3단계(초/중/고) 유지, 학습/피드백 중심
- **챌린지(Challenge)**: 흥미 유도용 **단일 규격(난이도 없음)**
  - 60초 고정 타임어택 + 콤보 점수
- **리더보드(Leaderboard)**: 현 단계에선 경쟁 의미가 약하므로 **숨김/준비중 권장**

---

## 1. 라우트/화면 정책
### HomePage (/)
- 연습 진입/설정(난이도 선택) 유지
- 챌린지 진입은 **버튼 1개**: `🔥 60초 챌린지`

### PracticePage (/practice)
- 기존 연습 흐름 유지(난이도 3단계)
- 챌린지 관련 분기(state/타이머/score/combo 등) 제거

### ResultPage (/result)
- 결과 타입 분기: `practice` / `challenge`
- **연습 결과에서만** CTA 노출: `🔥 60초 챌린지 해보기 → /challenge`
- 챌린지 결과는 Score 중심(Score/MaxCombo/Accuracy/WPM)

### HistoryPage (/history)
- 탭 2개: `연습` / `🔥 챌린지`
- 챌린지 탭: **최고기록 + 최근 10판**만

### LeaderboardPage (/leaderboard)
- 옵션 A(권장): 페이지 유지 + “추후 업데이트” 안내(네비게이션에서 숨김)
- 옵션 B: 라우트/기능 비활성

### ChallengePage (/challenge)
- **Start 버튼으로 시작**(자동 시작 제거, 모바일 포커스 안정)
- 60초 고정 + 콤보 점수
- 종료 시 `/result`로 결과 전달(state)

---

## 2. 챌린지 게임 규칙
- 시간: 60초 고정
- 정답 1글자: `+round(1 * multiplier)`
- 오타 1회: `-5`, `combo=0`
- multiplier: `1 + floor(combo/20)*0.25`, 최대 2.0(캡)

### 입력 처리(IME 안정)
- 숨김 input/textarea 사용
- `compositionstart/end`로 조합 상태 관리
- `input`에서 확정 입력(delta)만 처리
- input.value는 매번 `""`로 비움
- paste 차단(선택)

### 텍스트 표시
- 현재 텍스트 1개만 표시
- `done/current/rest` 3조각 렌더(성능/단순)
- 오타 시 짧은 이펙트(120ms)

---

## 3. 콘텐츠 운영(게임)
### 게임용 팩 선택(난이도 무시)
- 게임 전용 TextPack 1개만 사용(네이밍 룰 예: `[GAME]` 포함)

### 프리로드/리필/캐시
- 시작 시 items 200개 프리로드 → 셔플백
- 리필(권장 단순): **남은 30초 이하 진입 시 1회** 200개 추가
- 캐시: localStorage + 24h TTL(캐시 있으면 즉시 시작)
- 실패 시 fallback 단어 풀로 진행(플래시 감성: 끊기지 않게)

## 9) 화면별 와이어 흐름 (User Flow)

### 9.1 홈 → 연습
1. **/** (Home)
   - 연습 난이도 선택(초/중/고)
   - 연습 시작 버튼 → **/practice**
2. **/practice**
   - 타이핑 진행(연습 모드)
   - 완료/중단 → **/result** (resultType=practice)
3. **/result** (연습 결과)
   - 연습 결과(정확도/WPM/오타 등)
   - CTA: **🔥 60초 챌린지 해보기** → **/challenge**
   - 기록 보기 → **/history**

### 9.2 홈/연습결과 → 챌린지
1. **/challenge** (Ready 상태)
   - 규칙 안내 1줄
   - **Start 버튼**(모바일 포커스 안정 목적)
2. **/challenge** (Running 상태)
   - HUD: 남은시간/점수/콤보/최대콤보
   - 텍스트 1개 표시(done/current/rest)
   - 시간 종료 또는 종료 버튼 → **/result** (resultType=challenge)
3. **/result** (챌린지 결과)
   - Score 크게
   - MaxCombo/Accuracy/WPM/Errors
   - 다시하기 → **/challenge**
   - 기록 보기 → **/history**

### 9.3 기록
- **/history**
  - 탭: **연습** / **🔥 챌린지**
  - 챌린지 탭: 최고기록 + 최근 10판

## 10) 로컬 저장 키/스키마 표 (LocalStorage)

> 원칙: **연습은 기존 구조 유지**, **챌린지는 최소(최고 + 최근 10판)**

### 10.1 챌린지

| Key | 용도 | 스키마(요약) | 비고 |
|---|---|---|---|
| `typing:challenge_best` | 챌린지 최고기록 | `{ bestScore:number, bestMaxCombo:number, bestWpm:number, updated_at:number }` | 단일 규격이므로 난이도 분리 없음 |
| `typing:challenge_history` | 최근 10판 | `{ version:1, items: ChallengeSessionLocal[] }` | items는 최신순, 최대 10개 |
| `typing:cache_game_items_<packId>` | 게임 콘텐츠 캐시(TTL) | `{ version:1, savedAt:number, items:string[] }` | 24h TTL 권장 |
| `typing:cache_game_items_fallback` | fallback 콘텐츠 캐시 | `{ version:1, savedAt:number, items:string[] }` | pack 로딩 실패 시 사용 |
| `typing:uiFlags` | UI 플래그 | `{ seenChallengeIntro?: boolean }` | 첫 1회 안내 표시용(선택) |

#### ChallengeSessionLocal (요약)
```json
{
  "id": "local-<ts>",
  "playedAt": 1738890000000,
  "submode": "time_attack_combo",
  "base": {
    "durationMs": 60000,
    "wpm": 320.5,
    "accuracy": 96.2,
    "errorCount": 12,
    "correctChars": 410,
    "totalInputs": 426
  },
  "extra": {
    "score": 842,
    "maxCombo": 67,
    "timeLimitSec": 60,
    "packId": 123
  }
}
```

### 10.2 연습(기존 유지)
- 기존 사용 중인 `typing:history`, `typing:stats` 등이 있다면 그대로 유지
- 단, **챌린지와 키를 분리**해서 데이터 충돌을 방지

## 11) API 엔드포인트 표 (권장)

> 전제: 서버 API가 아직 정리되지 않았다면, 아래는 “최소 동작” 기준의 권장 설계.

### 11.1 콘텐츠(게임/연습 공용)

| Method | Path | Query/Body | 응답(요약) | 사용처 |
|---|---|---|---|---|
| GET | `/api/texts/packs` | `is_active=1` + (선택) 필터 | `[{id,title,...}]` | 연습/게임 pack 조회 |
| GET | `/api/texts/items` | `pack_id`, `is_active=1`, `limit`, (선택)`random=1` | `[{id,content,...}]` | 아이템 프리로드 |

### 11.2 챌린지(권장 편의 API)
| Method | Path | Query/Body | 응답(요약) | 비고 |
|---|---|---|---|---|
| GET | `/api/game/pack` | (선택) `lang=ko` | `{ pack_id:number }` | 서버가 `[GAME]` 규칙으로 1개 선택 |
| GET | `/api/game/items` | `pack_id`, `limit=200` | `[{id,content}]` | random 포함 가능하면 UX↑ |

> **현재 구현 템플릿은** `packs?title_contains=[GAME]` 방식으로도 충분히 동작.

### 11.3 세션 저장(추후 로그인 도입 전/후 모두 대비)
| Method | Path | Body | 응답 | 비고 |
|---|---|---|---|---|
| POST | `/api/sessions` | `TypingSession` | `{id,...}` | 로그인 없으면 서버 저장은 선택 사항(또는 익명 토큰) |

권장 Body(챌린지):
- `mode = "challenge"`
- `duration_ms = 60000`
- `accuracy, wpm, error_count, correct_length, input_length`
- `metadata.submode = "time_attack_combo"`
- `metadata.result_extra = { score, max_combo }`
