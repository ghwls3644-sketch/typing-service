## 1) Phase 1: 보안 취약점 (5건) ✅

### 1-1. 세션 API 권한 미설정
- **파일**: `backend/apps/sessions/views.py`
- **문제**: `TypingSessionViewSet`에 `AllowAny`만 있어 인증 없이 모든 세션 수정/삭제 가능
- **수정**: `IsOwnerOrReadOnly` 커스텀 퍼미션 추가 + `http_method_names = ['get', 'post', 'head', 'options']`로 PUT/PATCH/DELETE 차단

### 1-2. Import 엔드포인트 무검증
- **파일**: `backend/apps/sessions/views.py` (`import_data`)
- **문제**: 크기 제한/데이터 검증 없이 대량 데이터 임포트 가능
- **수정**: `MAX_IMPORT_SESSIONS=500`, mode/language 유효값 검증, WPM(0~500)/accuracy(0~100) 범위 체크, 에러 로깅

### 1-3. 챌린지 WPM/accuracy 조작 가능
- **파일**: `backend/apps/challenges/views.py` (`submit`)
- **문제**: 클라이언트가 보내는 WPM/accuracy를 그대로 저장
- **수정**: `MAX_WPM=500`, `MAX_ACCURACY=100` 서버 측 검증 추가

### 1-4. 프로필 username/email 변경 가능
- **파일**: `backend/apps/users/serializers.py`, `views.py`, `urls.py`
- **문제**: UserSerializer에서 username/email이 writable
- **수정**: `read_only_fields`에 추가, 별도 `ChangeEmailView` (비밀번호 확인 필수)

### 1-5. SECRET_KEY 프로덕션 검증 누락
- **파일**: `backend/config/settings/prod.py`
- **문제**: `SECRET_KEY`가 기본값으로 실행 가능
- **수정**: 환경변수 미설정 시 `ValueError` 발생, `ALLOWED_HOSTS` 검증, 로그 디렉토리 자동 생성

## 2) Phase 2: 데이터 정합성 (5건) ✅

### 2-1. 일일 통계 race condition
- **파일**: `backend/apps/sessions/views.py` (`_update_user_daily_stats`, `_update_client_daily_stats`)
- **문제**: read-modify-write 패턴으로 동시 요청 시 데이터 유실
- **수정**: Django `F()` 표현식으로 atomic 업데이트

### 2-2. 스트릭 업데이트 race condition
- **파일**: `backend/apps/goals/models.py` (`UserStreak.update_streak`, `ClientStreak.update_streak`)
- **문제**: 동시 요청 시 스트릭 값 덮어쓰기
- **수정**: `@transaction.atomic` + `select_for_update()` 행 잠금, 미래 날짜 보호

### 2-3. perform_create 이중 집계
- **파일**: `backend/apps/sessions/views.py` (`perform_create`)
- **문제**: `if user ... if guest` 구조로 인증 사용자+guest_session_id 동시 존재 시 이중 집계
- **수정**: `if ... elif` 로 변경

### 2-4. date.today() 시간대 미고려
- **파일**: `sessions/views.py`, `challenges/views.py`, `stats/views.py`, `goals/views.py`
- **문제**: `date.today()`는 서버 시간대 기준 → KST와 불일치 가능
- **수정**: 전체 `timezone.localdate()`로 통일

### 2-5. 파라미터 검증 누락
- **파일**: `stats/views.py`, `texts/views.py`
- **문제**: `int()` 변환 시 `ValueError` 미처리
- **수정**: `try/except` 추가, 400 에러 반환

## 3) Phase 3: 프론트엔드 핵심 버그 (9건) ✅

### 3-1. PracticeMode 타입 불일치
- **파일**: `frontend/src/types/practice.ts`
- **수정**: `PracticeMode`를 7개 모드로 확장, `PracticeSettings`에 `timeLimitSec/maxErrors/minAccuracy` 추가

### 3-2. WPM 계산 부정확
- **파일**: `frontend/src/hooks/useTypingEngine.ts`
- **문제**: 단어 수 기반 → 한글에 부적합
- **수정**: 문자 기반 `(correct / 5) / minutes`로 변경

### 3-3. 완성 조건 누락
- **파일**: `frontend/src/hooks/useTypingEngine.ts`
- **문제**: `value.length > targetText.length` → 정확히 같을 때 미완료
- **수정**: `>=`로 변경

### 3-4. useChallengeEngine setState 사이드이펙트
- **파일**: `frontend/src/hooks/useChallengeEngine.ts`
- **문제**: `setStats` updater 안에서 `onComplete` 호출 → React 18 StrictMode 위반
- **수정**: `useEffect`로 `phase === 'finished'` 감지하여 외부에서 호출

### 3-5. ChallengePage 의존성 배열 누락
- **파일**: `frontend/src/pages/ChallengePage.tsx`
- **수정**: `handleComplete`의 deps에 `isBlindMode` 추가

### 3-6. PracticePage 순환 참조 + stale closure
- **파일**: `frontend/src/pages/PracticePage.tsx`
- **문제**: `handleItemComplete` → `reset` → `useTypingEngine` → `onComplete` 순환 의존, `userInput` 선언 전 참조
- **수정**: `useTypingEngine`을 먼저 선언, `onComplete` 대신 `isFinished` useEffect로 완료 감지, `stateRef`로 최신 state 추적

### 3-7. PracticePage fetchPracticeItems 타입 에러
- **파일**: `frontend/src/pages/PracticePage.tsx`
- **문제**: `PracticeMode`(7개)를 `'word'|'short'` 파라미터에 직접 전달 → TS2345
- **수정**: `apiMode` 매핑 변수 추가

### 3-8. HistoryPage 하드코딩 데이터
- **파일**: `frontend/src/pages/HistoryPage.tsx`
- **문제**: 실제 API 대신 샘플 데이터 사용
- **수정**: `fetchRecentSessions` API 연동

### 3-9. ResultPage/LeaderboardPage 에러 처리
- **파일**: `frontend/src/pages/ResultPage.tsx`, `LeaderboardPage.tsx`
- **수정**: division by zero 방어, `getModeName` 타입 수정, `Promise.allSettled` 에러 처리

## 4) Phase 4: 성능 최적화 (5건) ✅

### 4-1. 메모리 기반 랜덤 선택
- **파일**: `backend/apps/texts/views.py`
- **문제**: `random.choice(list(queryset))` → 전체 로드 후 선택
- **수정**: `queryset.order_by('?').first()` DB 레벨 랜덤

### 4-2. TextPackListSerializer N+1 쿼리
- **파일**: `backend/apps/texts/views.py`
- **문제**: `item_count` 프로퍼티가 팩마다 쿼리 실행
- **수정**: `annotate(item_count=Count(...))` DB 레벨 집계

### 4-3. 챌린지 ranking N+1
- **파일**: `backend/apps/challenges/views.py`
- **문제**: `uc.user.nickname` 접근 시 유저별 쿼리
- **수정**: `select_related('user')` 추가

### 4-4. 리더보드 language 필터 미적용
- **파일**: `backend/apps/leaderboard/views.py`
- **문제**: `latest` 엔드포인트에서 language 파라미터 무시
- **수정**: `if language: qs = qs.filter(language=language)` 추가

### 4-5. Export 페이지네이션 미구현
- **파일**: `backend/apps/sessions/views.py` (`export_data`)
- **문제**: 전체 세션을 한 번에 로드 → 대량 데이터 시 메모리 폭발
- **수정**: `offset/limit` 페이지네이션 + `iterator()`, `MAX_EXPORT_SESSIONS=5000`
