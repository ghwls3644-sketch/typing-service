# 타자 연습 콘텐츠 스펙 v4.0 (최종 정리본)

## 1. 핵심 원칙
- 연습 모드: **2개**
  1) **단어 연습(Word)**: KO/EN  
  2) **짧은 글 연습(Short)**: KO/EN, **속담 원문만**
- 난이도: **3단계(초급/중급/고급)** 고정
- 데이터 수집: **배치 수집 → DB 적재 → DB 서빙**
- 품질/운영: **정규화 + 강한 필터 + 중복 제거(normalized_content)**

---

## 2. 콘텐츠 정의

### 2.1 단어 연습 (Word)
- 단위: 단어 1개(공백 없음)
- 허용(기본):
  - KO: 한글 음절만
  - EN: 영문 알파벳만
- 제외:
  - 공백 포함, URL/이메일, 숫자만, 특수문자 과다, 자모 분리(ㄱㅏ)

### 2.2 짧은 글 연습 (Short = Proverbs only)
- 단위: 속담 원문 1개(한 줄)
- 허용(운영 단순화 “강한 컷”):
  - KO: **한글 + 공백만**
  - EN: **영문 + 공백만**
- 제외:
  - 해설/예문/각색/설명형
  - 숫자 포함, 괄호/따옴표/특수문자/이모지 포함
  - 길이 상한 초과(아래 컷 적용)

---

## 3. 난이도 기준(3단계)

### 3.1 단어(Word)
- KO:
  - 초급(1): 2~3글자
  - 중급(2): 4~5글자
  - 고급(3): 6글자
- EN:
  - 초급(1): 2~4 chars
  - 중급(2): 5~7 chars
  - 고급(3): 8~10 chars
  - (선택) `-`, `'` 포함은 고급 전용

### 3.2 속담(Short)
- KO(공백 포함):
  - 초급(1): 8~18자
  - 중급(2): 19~30자
  - 고급(3): 31~60자
  - 60 초과: 제외
- EN(공백 포함):
  - 초급(1): 15~40 chars
  - 중급(2): 41~75 chars
  - 고급(3): 76~120 chars
  - 120 초과: 제외

---

## 4. 정규화/필터링(통일 지침)

### 4.1 공통 정규화
- trim(앞뒤 공백 제거)
- 내부 연속 공백 1개로 축약
- 제로폭/제어문자 제거
- KO NFC 정규화
- (속담) 끝 문장부호 제거(최소 `. ! ?`)

### 4.2 공통 금지
- URL/이메일 포함
- 개인정보 패턴 의심(전화번호 등)
- 욕설/혐오/성적 표현(블랙리스트)

---

## 5. 중복 정책
- `normalized_content` 생성 후 이를 기준으로 중복 제거
- 유니크 기준: **(pack_id, normalized_content)**

`normalized_content` 규칙(권장)
- 공백 정리(1개)
- 끝 문장부호 제거
- EN은 중복 판정용으로 소문자화(표시는 원문 유지 가능)

---

## 6. 팩 구조(최소 12개)
팩은 자동 생성되며, 서비스는 팩을 직접 고르게 하지 않는다.

### 6.1 단어팩(6)
- `ko-word-daily-1`, `ko-word-daily-2`, `ko-word-daily-3`
- `en-word-daily-1`, `en-word-daily-2`, `en-word-daily-3`

### 6.2 속담팩(6)
- `ko-short-proverb-1`, `ko-short-proverb-2`, `ko-short-proverb-3`
- `en-short-proverb-1`, `en-short-proverb-2`, `en-short-proverb-3`

---

## 7. DB/모델 변경 요약

### 7.1 TextPack
- `difficulty`: **1~3만 사용**
- 추가 권장:
  - `kind`: `word|short`
  - `theme`: `daily|proverb`
  - (선택) `code`: `ko-word-daily-1` 같은 안정 식별자
- 인덱스 권장:
  - `(language, kind, theme, difficulty, is_active)`
- 유일성 권장:
  - `UNIQUE(language, kind, theme, difficulty, created_by_id)` 또는 `UNIQUE(code)`

### 7.2 TextItem
- 필수 추가: `normalized_content`
- 권장 추가: `source_name`, `source_ref`, `source_url`, `import_batch_id`, `license_note`
- 유니크: `UNIQUE(pack_id, normalized_content)`

### 7.3 난이도 1~5 → 1~3 마이그레이션
- 1~2 → 1
- 3 → 2
- 4~5 → 3

## 9. API(서빙 단순화)

### 9.1 연습 데이터 요청
`GET /api/practice/items?mode=word|short&language=ko|en&difficulty=1|2|3&count=N`

### 9.2 서버 처리
- pack 선택:
  - `language`
  - `kind=mode`
  - `theme= daily(word) / proverb(short)`
  - `difficulty`
  - `is_active=true`
- item 선택:
  - 해당 pack의 active 아이템 중 랜덤 N개

## 10. 관리자/운영(최소 + 권장)

### 10.1 최소 기능(필수)
- Pack 목록(필터 + is_active 토글)
- Item 검색(content/normalized_content) + 비활성화 토글

### 10.2 권장 기능(운영 안정화)

- DroppedSample(탈락 샘플): 배치당 50개 저장 + drop_reason 분포 확인
- batch_id/source_name 기준 일괄 비활성화
